wasm-mcp

Unofficial, read-only Model Context Protocol server over the WebAssembly specification.

Not affiliated with the W3C WebAssembly Community Group or Working Group. Every tool is a deterministic local lookup over spec data pinned to a specific upstream commit — read-only, no execution, no auth, no network at request time.

Connect

Streamable-HTTP MCP endpoint:

POST /mcp

Or run locally over stdio:

npx wasm-mcp
